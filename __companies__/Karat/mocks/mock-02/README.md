# Karat Mock 02

This is a representative IC3-IC4 real-world coding mock. It is not an active Karat question.

## Format (50 minutes)

1. Introductions and setup: **5 minutes**
2. Debugging: **15 minutes**
3. Progressive implementation: **25 minutes**
4. Wrap-up: **5 minutes**

Complete `debugging` first. Then open `progressive` as a separate VS Code workspace.

The supplied Xero interview description is coding-focused. System design is therefore not included in this mock; the separate system-design guide describes a different, approximately one-hour interview format.

## What to practise

- Read and run the existing code before editing.
- State the root cause or implementation plan before changing code.
- Ask clarifying questions when a requirement is ambiguous.
- Make the smallest clean change at the correct integration point.
- Test incrementally and explain edge cases and complexity.
