# Karat Interview Improvements



## Implementation

- Practise tuple-based sorting with `sorted(..., key=...)`.
- Fetch full records once; avoid repeated lookups.
- Choose data structures based on scope and access patterns.
- Prefer validate-then-commit over copying and rollback.
- Use descriptive `snake_case` and private helper methods.

## Communication

- Ask questions only for genuine ambiguity.
- Restate the plan once, then implement.
- Select the structure and integration point independently.
- Summarize correctness and complexity without prompting.
  
## Final checklist

1. Restate requirements, edge cases, and plan.
2. Implement and run all tests.
3. Clean up names and temporary notes.
4. Explain correctness, time, and space complexity.

## Complexity

- Define variables before analyzing complexity.
- Do not multiply by a count already defined as a total.
- Include sorting, temporary collections, and output.
